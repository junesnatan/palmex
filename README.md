# Palmex Agro-Industrielle SARL

Site vitrine institutionnel et plateforme de présentation des investissements agricoles pour **Palmex Agro-Industrielle SARL**, cabinet d'ingénierie agronomique et de gestion déléguée de palmeraies industrielles au Bénin.

---

## 🌴 Mission & Garanties

- **Mission** : Sécuriser et optimiser vos investissements agricoles sur 25 ans.
- **Garanties Contractuelles** :
  - Sous seing foncier certifié et sous Titre Foncier (TF) inattaquable
  - Plants hybrides certifiés CRAPP (INERA / CRAPP - Tenera élite)
  - Ingénierie foncière & topographie agricole
  - Aménagement géométrique & piquetage au cordeau en triangle équilatéral (143 plants/ha)
  - Gestion et conduite agronomique déléguée (clés en main)
  - Intégration et débouchés industriels garantis auprès des huileries

## 🛠️ Stack Technique

- **Framework** : React 18 + Vite 6
- **Styling** : Tailwind CSS + PostCSS + Autoprefixer
- **Icônes** : Lucide React (Zéro emoji, 100% vectoriel)
- **Déploiement** : Vercel / GitHub Pages
